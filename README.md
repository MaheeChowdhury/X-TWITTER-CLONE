This project uses Vite and Tailwind CSS v3. Vite processes the Tailwind directives in `css/input.css` and reloads the page when you change the HTML or CSS.

```sh
npm run dev
```

Open the local URL printed by Vite in the terminal, usually `http://localhost:5173`. You do not need to run Tailwind's watch command or Live Server alongside Vite.

The standalone Tailwind CSS commands are also available if you need to generate or watch `css/output.css` directly:

```sh
npm run build
npm run watch
```

If Tailwind CSS IntelliSense stops working, open the Command Palette with `Ctrl+Shift+P` and run **Tailwind CSS: Restart Language Server**.
